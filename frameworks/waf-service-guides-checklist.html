WAF — enumerated source for the Well-Architected service guides ​

Enumerated 2026-11-25. Verification method and limits are stated below — read them before quoting any coverage number from this page.

Scout's waf.serviceguides.yaml scores an estate against the "Configuration recommendations" that Microsoft publishes in each Azure Well-Architected Framework service guide. This page enumerates the recommendations Scout turns into a rule. src/assess/rules/waf.serviceguides.yaml is written against this page only, and every rule cites an item number from the tables below.

Source ​

FieldValue
AssessmentWell-Architected Framework perspective on Azure services (20 service guides read; Microsoft publishes no assessment questions for them)
Framework versionAzure Well-Architected Framework service guides on Microsoft Learn, current; guide pages last updated between 2025-02 and 2026-11
Extraction date2026-11-25
Verification methodEach guide page below was fetched in full on 2026-11-25 (the Azure Kubernetes Service and App Service guides with the Microsoft Learn MCP microsoft_docs_fetch tool, the rest from the Microsoft Learn markdown endpoint, which serves the same page), and its Configuration recommendations tables, workload design checklists and Azure policies sections were read. Every field an automated item reads was checked against the collect contract in src/collect/Invoke-Collect.ps1 and the KQL that projects it.

The one thing this enumeration is NOT ​

It is not a list Microsoft numbers. The guides carry unnumbered recommendation tables, and Microsoft publishes no assessment for them. The items below are Scout's reading of those tables, and the WAF-SVC-* IDs are Scout's. Where one recommendation is split across several settings, each setting is its own item; where a recommendation is a process (rehearse a failover, review a policy), it is a manual item.

Two of the guides are not in the index page's list but are published and are covered: Azure Container Apps and Azure Virtual WAN. The Virtual Machines guide covers virtual machines and scale sets together, so scale-set items carry their own WAF-SVC-VMSS prefix. The guides for Blob Storage, Cosmos DB, MySQL, PostgreSQL, SQL, Managed Redis, Databricks, Event Hubs, Machine Learning, Azure Local, Log Analytics, Service Fabric and HorizonDB are not enumerated here; several are already scored by their own rule files.

Reading the tables ​

  • Scout ✅ means a collected field answers the item, and the rule lists the resources that break it. Scout ❌ Manual means no collected field answers it; where there is some related evidence it is attached to the question.
  • Automated items are gated: they run only when the guide's resource type exists, so an estate without it reports the item Not assessed. Manual items are gated the same way.
  • Zone items are limited to the regions in Scout's zone-eligible list. A resource in a region without availability zones is not failed for lacking them.
  • Recommendations that conflict across pillars (a Premium tier for reliability against Basic for cost, scale to zero against replica counts) are scored on the stricter reliability or security reading at low or medium severity, and the remediation says when a lower setting is legitimate.

What these rules read ​

The rules read the fields the assessment collection gained in AB#9300 phase 4, such as AKS disableLocalAccounts, upgradeChannel and authorizedIpRangeCount; web app and Container Apps exposure fields; API Management zoneCount and capacity; Service Bus, Event Grid and storage TLS and local-authentication settings; Firewall, Application Gateway and Load Balancer zone, tier and probe fields; virtual network encryptionEnabled, publicIPAddresses and flowLogs; and virtual machine, scale set and disk security fields. Only a boolean or a count is collected for anything sensitive: no key, certificate, secret value, IP address list or workspace id is read.

Four items read the per-resource ARM settings added in AB#9300 phase 4, batch 2, each from a dataset with a sibling <name>Measured flag: App Service configuration (webAppConfig) and basic-authentication policies (webAppBasicAuth) for WAF-SVC-APP-13 and APP-14, and the Azure Files service properties (fileServiceProperties) for WAF-SVC-FILES-05 and FILES-06. The rule is gated on that flag, so a run that never read the setting reports the item Not assessed rather than passed. A site, account or policy whose read failed has no row and is not scored. Only a boolean, a count or a protocol string is collected: no app setting, connection string or credential is read.

Virtual network flow logs are matched to virtual networks by lower-cased resource id. A flow log whose target is a subnet or a network interface is not matched, and NSG flow logs (which Microsoft is retiring) are not counted as virtual network flow logs.
