Generative AI -- enumerated source for the Technical Assessment for Generative AI in Azure ​

Enumerated 2026-11-25. Verification method and limits are stated below -- read them before quoting any coverage number from this page.

Scout's genai.technical.yaml scores the review in Microsoft's Technical Assessment for Generative AI in Azure, which checks a team's readiness to develop, run and maintain Azure AI solutions in production. src/assess/rules/genai.technical.yaml is written against this page only, and every rule cites an item number from the tables below. The design and operating practices are manual questions answered with -AssessmentAnswers; the platform configuration Azure data can show is automated.

Source ​

FieldValue
AssessmentTechnical Assessment for Generative AI in Azure (question text not published)
Framework versionWell-Architected AI workload guidance and Microsoft Foundry guidance on Microsoft Learn, current as of the extraction date (no published version number)
Extraction date2026-11-25
Verification methodEach source page below was fetched or searched with the Microsoft Learn MCP tools (microsoft_docs_fetch, microsoft_docs_search) on 2026-11-25. Every property an automated item reads was checked against the collect.json contract in src/collect/Invoke-Collect.ps1.

The one thing this enumeration is NOT ​

It is not Microsoft's question list. The assessment's questions are not published, so the items below are Scout-derived: Scout's reading of the Well-Architected AI workload guidance and the Microsoft Foundry guidance, grouped into eight readiness areas of Scout's own. The GENAI-* IDs are Scout's. The area grouping is Scout's judgement, not Microsoft's. This page overlaps waf-ai-workload-checklist.md on purpose: that page reviews a workload against design areas, this one asks whether the team and platform are ready for production.

Sources:

  • [WAFO] MLOps and GenAIOps for AI workloads on Azure (WAF AI workload)
  • [OPS] AI workload operations on Azure (WAF AI workload)
  • [RAIP] Responsible AI in Azure workloads (WAF AI workload)
  • [GAO] Generative AI operations for organizations with MLOps investments
  • [BSL] Baseline Microsoft Foundry chat reference architecture
  • [FND] Microsoft Foundry architecture
  • [NIS] How to configure network isolation for Microsoft Foundry
  • [SECB] Azure security baseline for Microsoft Foundry
  • [GOVP] Govern Azure platform services (PaaS) for AI
  • [GOVI] Governance for AI on Azure infrastructure
  • [SECP] Secure Azure platform services (PaaS) for AI
  • [SEC] Guidance to set up your organization's AI security process

Automated items are gated: they run only when the resources they judge exist, so an estate without them reports those items Not assessed rather than passed or failed. Manual items are answered with -AssessmentAnswers (see Questionnaire Answers); where collected Azure data bears on the question it is attached to the item as evidence.
